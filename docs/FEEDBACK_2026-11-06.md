Three issues found while testing US23-US41 were fixed. 测试中发现的三个问题已修正：先写测试并确认在旧代码上失败，再修改代码，最后全部通过。

| # | Issue | Fix |
|---|---|---|
| 1 | On My Interior Design Projects, keyword search and the status filter did not work together | One form now carries both the keyword and the status. Search and Apply Filter both use both. | 2 | Save to Favourites (US19) jumped to My Favourites | The Customer stays on the project page. The button saves in the background and shows "Saved to your favourites. View My Favourites" in place, and the button becomes "In your favourites". The page is not reloaded, so no extra view is recorded (US18 counts one view per opening; checked in the browser). Without JavaScript the form still works and returns to the same project. An expired session goes to the login page. |
| 3 | "Project created. Customers can now find it." read oddly | US26 now shows "Project created successfully." |

第二轮修正：同样先写测试并确认失败，再修改代码，最后全部通过。

| # | Issue | Fix |
|---|---|---|
| 1 | After opening a project from Browse IDPs, Back to projects always went to page 1 | Project links now carry the list page and filters (`?page=3&status=PAST`), and Back to projects returns to exactly that page with the same filters. | 2 | My Interior Design Projects had two buttons (Search and Apply Filter) that did the same thing | It now uses the same filter box as Browse IDPs: Keyword and Status, one **Apply filters** button, **Clear all**, and "Projects must match all selected filters." on the left. A blank keyword now simply means "no keyword"; US31's "Please enter a keyword." is still enforced by its Controller. |
| 3 | Browse IDPs only had Previous/Next | Page numbers (first, last and two either side of the current page, with … between) and a **Go to page** box. The box keeps the filters. A page number that does not exist shows "Page 9 does not exist. There are 4 page(s)." |

Tests changed because of the intended new behaviour: three project-ID patterns in `test_combined_filters_and_photos.py` and `test_us01_us22_acceptance.py` now accept the `?page=…` part of project links; the morning check that used the removed Search button now checks US31's rule at the Controller; one US28 page check looks for "Clear all".
